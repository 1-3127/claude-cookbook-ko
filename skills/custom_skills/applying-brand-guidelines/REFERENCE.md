# Brand 지침 Reference

## 빠른 Reference Card

### 필수 요소
✅ 첫 페이지/slide의 회사 logo
✅ 정확한 brand 색상(변형 없음)
✅ 승인된 font만 사용
✅ 전체에서 일관된 서식
✅ 전문적인 어조

### 사용 금지
❌ 경쟁사 logo나 언급
❌ 승인되지 않은 색상이나 gradient
❌ 장식 또는 script font
❌ pixel이 보이거나 늘어난 logo
❌ 비격식적인 언어나 slang

## 접근성 기준

### 색상 대비
- 흰 배경의 텍스트: Acme Navy(#003366) 사용
- 파란 배경의 텍스트: 흰색(#FFFFFF) 사용
- 최소 대비 비율: 본문 4.5:1
- 최소 대비 비율: 큰 텍스트 3:1

### Font 크기
- 최소 본문: 11pt(인쇄), 14px(digital)
- 최소 caption: 9pt(인쇄), 12px(digital)

## 파일 Naming 규칙

### 표준 형식
```
YYYY-MM-DD_DocumentType_Version_Status.ext
```

### 예제
- `2025-01-15_QuarterlyReport_v2_FINAL.pptx`
- `2025-01-15_BudgetAnalysis_v1_DRAFT.xlsx`
- `2025-01-15_Proposal_v3_APPROVED.pdf`

## 피할 흔한 실수

1. **잘못된 파란색**: Acme Blue #0066CC 대신 일반 파란색 사용
2. **늘어난 Logo**: 항상 종횡비 유지
3. **너무 많은 색상**: 승인된 palette 유지
4. **일관되지 않은 Font**: font family 혼합 금지
5. **Logo 누락**: 항상 첫 페이지에 포함
6. **잘못된 날짜 형식**: "Month DD, YYYY" 사용
7. **소수 자릿수**: 일관성 유지(통화: 2, 백분율: 1)

## 부서별 지침

### 재무
- table의 숫자는 항상 오른쪽 정렬
- 음수는 괄호 사용: ($1,234)
- data source citation 포함

### Marketing
- 전체 보조 color palette 사용 가능
- 승인된 이미지 포함 가능
- 해당하면 social media별 지침 준수

### 법무
- 번호가 붙은 section 사용(1.0, 1.1, 1.2)
- 문서 관리 정보 포함
- 필요 시 "Confidential" watermark 적용

## 국제적 고려 사항

### 지역별 날짜 형식
- **US**: Month DD, YYYY (January 15, 2025)
- **UK**: DD Month YYYY (15 January 2025)
- **ISO**: YYYY-MM-DD (2025-01-15)

### 통화 표시
- **USD**: $1,234.56
- **EUR**: €1.234,56
- **GBP**: £1,234.56
